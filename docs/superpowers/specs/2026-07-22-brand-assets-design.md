# Honkumi ブランド素材組み込みデザイン

## 目的

指定されたブランド素材をサポートサイトへ組み込み、ブラウザタブとトップページの双方で Honkumi のブランドを認識できるようにする。

## 対象素材

- `logo.svg`: ブラウザタブのファビコンとして使用する。
- `title.svg`: トップページのヒーロー内にワードマークとして表示する。

## ページ構成

トップページのヒーロー上部にあるテキスト「Honkumi Support」を `title.svg` に置き換える。既存の見出し「Honkumi サポート」と説明文は残し、ワードマークをブランド表示、見出しをページの目的を示す情報として使い分ける。

`title.svg` はデスクトップで横幅 220〜280px 程度を上限とし、縦横比を維持する。狭い画面では利用可能な横幅に合わせて縮小し、はみ出さないようにする。既存の濃紺と金を基調とした背景、余白、区切り線との調和を保つ。

## 実装方針

- SVG素材を Next.js が配信できるアプリ内の適切な場所へ追加する。
- `logo.svg` は Next.js App Router のアイコン規約に沿って設定する。
- `title.svg` は Next.js の画像コンポーネントで表示し、表示寸法を明示してレイアウトずれを防ぐ。
- ワードマークには内容を示す代替テキストを設定する。
- 既存の未関連ファイルおよびプライバシーページの作業中変更には触れない。

## 確認項目

- ブラウザタブに新しいファビコンが表示される。
- トップページのヒーロー上部にワードマークが表示される。
- 「Honkumi サポート」の見出しと説明文が従来どおり読める。
- デスクトップとスマートフォンの双方で画像がはみ出さず、縦横比が保たれる。
- lint と production build が成功する。
